chatByte is a lightweight, real-time chat application built with Node.js, Express, and Socket.io that lets users join chat rooms, pick a username, and message each other instantly — no signup or database required. It features real-time messaging over WebSockets, multiple chat rooms, a live user list, typing indicators, message timestamps, XSS-safe rendering, and a clean dark UI built with vanilla HTML, CSS, and JavaScript. The project is structured with a public/ folder containing the client files (index.html, style.css, chat.js) and a root-level server.js that runs the Express server and handles all Socket.io events (joinRoom, chatMessage, typing, message, userTyping, userList). To run it locally, clone the repo, run npm install, then npm run dev and open http://localhost:3000 in two browser tabs to test it. The roadmap includes future additions like message persistence, private DMs, user authentication, file sharing, read receipts, and production deployment, and it's released under the MIT license.
